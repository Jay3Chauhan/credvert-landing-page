# Credvert Web Application — Architecture & Design Rules

## Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript 5+ (Strict mode, zero `any`)
- **Styling**: Tailwind CSS (Dark Obsidian luxury design tokens)
- **Motion**: Framer Motion (Apple-style spring physics & scroll progress)
- **Domain**: `https://credvert.tech`

## UI/UX & Motion Standards (Apple Design Skills)
1. **Spring-Based Physics**:
   - Critically damped (`bounce: 0`, `duration: 0.35s`) for UI transitions.
   - Bouncy springs (`bounce: 0.2`, `duration: 0.4s`) reserved exclusively for physical flicks and drag releases.
2. **Interactive 3D Perspective**:
   - Hero card tilt with smooth spring tracking on pointer move.
   - Dynamic specular sheen reacting to pointer coordinates (`(x, y)` percentages).
   - Biometric scan laser effect and 3D card flip (`rotateY(180deg)`).
3. **Accessibility**:
   - Full keyboard navigation and ARIA landmarks.
   - Respect `@media (prefers-reduced-motion)` by bypassing motion transforms.
   - High contrast borders (`border-white/10`) for readability on deep obsidian backgrounds.
